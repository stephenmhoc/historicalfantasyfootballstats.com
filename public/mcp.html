Historical Fantasy Football Stats

Fantasy Football MCP Server

Give your AI agent every NFL fantasy season since 1970, plus live weekly stats for the current season. It's free and open, with no API key or account.

Connect in one step

Add this URL to any client that supports remote MCP servers:

https://historicalfantasyfootballstats.com/mcp

Claude Code

claude mcp add --transport http fantasy-stats https://historicalfantasyfootballstats.com/mcp

Claude

Open Settings, go to Connectors, add a custom connector, and paste the URL above.

Cursor

Add this to .cursor/mcp.json:

{
  "mcpServers": {
    "fantasy-stats": {
      "url": "https://historicalfantasyfootballstats.com/mcp"
    }
  }
}

VS Code

Add this to .vscode/mcp.json:

{
  "servers": {
    "fantasy-stats": {
      "type": "http",
      "url": "https://historicalfantasyfootballstats.com/mcp"
    }
  }
}

Tools

Tool What it does
get_data_info Seasons covered, the latest week, freshness, and known caveats
search_players Finds players by full or partial name
get_player_stats Season-by-season stats and career totals
get_player_weekly Game-by-game stats for seasons with weekly data
get_leaders Ranks seasons, single weeks, careers, or points per game

Custom scoring

Tools that return fantasy points accept a preset of ppr, half_ppr, or standard, and any individual override. For example, this scores half-PPR with 6-point passing touchdowns: 

{ "preset": "half_ppr", "passingTD": 6 }

Data

  • QBs, RBs, WRs, and TEs, regular season only.
  • Seasons from 1970 through 2025 come from Pro Football Reference.
  • Seasons from 2026 onward come from nflverse and update daily.
  • Targets before 1992 and fumbles lost before 1994 are estimates.

Frequently asked questions

What is an MCP server?

The Model Context Protocol is an open standard that lets AI applications use outside tools and data. This server gives them fantasy football stats they can look up instead of guessing.

Does it cost anything?

No. It's free, and there is no API key, account, or sign-up.

Are there rate limits?

Yes. Each IP address is limited to about 10 requests every 10 seconds, and a shared daily limit applies. If you hit a limit, the server responds with HTTP 429 or stops until the daily reset at midnight UTC.

Which protocol versions does it support?

It uses Streamable HTTP and supports MCP versions 2025-03-26 through 2026-07-28. The server is read-only.

Is the code open source?

Yes. It's on GitHub under the MIT license.
